# lumorphia/scenote

Scenote: FINAL FANTASY XIV で撮った風景・日常・旅・記念撮影のスクリーンショットを、ブラウザで現像して記録・共有する Web サービス。Lumorphia のサービスのひとつで、現像は [lumorphia/editor](https://github.com/lumorphia/editor)、ログインは [Lumorphia アカウント](https://github.com/lumorphia/accounts) を使う。

要件は [docs/scenote_要件定義書.md](docs/scenote_要件定義書.md)、判断は [docs/adr/](docs/adr/)、弱点の知らせ方は [SECURITY.md](SECURITY.md)。今は骨組みを作る前の段階。
