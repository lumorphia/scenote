# ADR-0026: 冒険者の写真日誌としてトップと投稿詳細を整える

| 項目     | 内容       |
| -------- | ---------- |
| Status   | Accepted   |
| Date     | 2026-10-18 |
| Deciders | t1nyb0x    |

## Context

Scenote は写真を現像し、どこでどんな時間を過ごしたかを残す場所である。旅の手帳、冒険の野帳、日常の写真帳の 3 案を HTML で比較し、A 案の旅の手帳を基本に、トップのヒーローだけ C 案の写真帳を使う方針が承認された。

## Decision

- 紙色と深緑のインク、明朝の見出し、薄い罫線を使う。トップは写真を少し傾けて並べた表紙、新着の写真、地図から探す、編集の入口の順とする
- ヒーローは新着の公開写真から最大 3 枚を選ぶ。横写真を優先し、足りなければ縦写真を使う。投稿がないときだけ、運営者の写真を同梱したブランド画像を出す。架空の投稿情報は表示しない
- SSR は既存の load context (ADR-0018) から公開の一覧と撮影場所を読み、新着の最初のページにも使う。トップは no-store とする
- 写真は切り抜かず、元の縦横比を保つ。一覧の低い列に積む方針 (ADR-0016) は継続し、PC は 3 列、ほかは 2 列とする
- 投稿詳細は PC で左に写真、右に投稿情報、スマートフォンは上下に並べる。写真の拡大、撮影場所の地図を追加し、公開範囲・タグ・場所の変更、削除、通報は引き継ぐ
- 地図は現時点の撮影場所候補に対応する 79 エリアを同梱する。XIVAPI の TerritoryType.Map.Id と PlaceName の row_id を対応させる。地名同期と同じ対象・重複排除の順で作る。取得元と日時を画像と一緒に記録する
- 撮影座標は保存していないので、撮影地点のピンは置かない。地域とエリアを選ぶと、その地図と公開写真を表示する。自由入力・未登録・未対応の場所に別の地図を推測して当てない
- 一覧 API は撮影日・場所を返し、placeId でも絞れる。公開・処理済み・有効な投稿者の条件はすべての一覧で共通とする
- 操作の文言は「写真を編集する」など平らに書く。端末ごとの配色切り替えを提供し、選んでいない場合は OS の配色に従う

## Consequences

写真と場所を行き来しながら旅や日常を振り返れる。閲覧時に XIVAPI へ通信しない。撮影座標やアルバム機能は追加せず、スキーマの変更も不要。

地図を更新するときは `pnpm --filter @lumorphia-scenote/app exec node scripts/sync-map-assets.ts` を実行し、整形と差分の確認を行う。新しい地名の同期と画像の追加は別なので、未対応の場所には地図を出さない。
