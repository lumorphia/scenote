# プライバシーポリシー

Scenote (以下「本サービス」) が、利用者のどのような情報を、何のために取得し、どこへ送り、いつ消すかを説明します。

## 1. 取得する情報

### アカウント

**Lumorphia アカウント** (本サービスと同じ運営者が運営する共通アカウント) でログインしたときに、次の情報を受け取ります。

- Lumorphia アカウントの ID
- ID (handle)、名前、アイコンの URL。本サービスはこれを写して表示し、ログインのたびに新しくします。変更は Lumorphia アカウントで行います
- アカウントの状態 (退会・復旧・削除とその日時)
- ログインの記録に使う、Lumorphia のセッションの ID とログインの証明 (ID トークン)。ログアウトを Lumorphia と揃えるためだけに使い、セッションと一緒に削除します

メールアドレスは、ログインのときに Lumorphia アカウントから届きますが、保存しません。メールアドレスで別のアカウントと結び付けることもしません。

本サービスで記録する情報: 利用規約とプライバシーポリシーに同意した版と日時、15 歳以上であることの確認。

### 投稿

画像 (後述)、タイトル、ひとこと、タグ、撮影日、撮影場所、公開範囲、現像の内容 (レシピ)、投稿日時。

画像の自動判定の結果 (判定の種類ごとの数値と、保留・要確認・問題なしの区分) を、投稿と一緒に保存します。

### 通報

通報した人のアカウント、通報した投稿、理由、書いた内容、日時。通報した人は、運営の画面にも表示しません。

### 通信に関する情報

- **ログイン時の IP アドレスとブラウザの種類 (User-Agent)** を、ログインの記録 (セッション) として保存します。不正なログインの確認と、法令に基づく要請への対応のためです。セッションと一緒に削除します (ログアウトまたは有効期限で、最長 30 日)
- それ以外の IP アドレスは、過度なアクセスを制限するためにサーバーのメモリ上でのみ扱い、ログやデータベースには保存しません。投稿に IP アドレスは記録しません
- 本サービスへの通信はすべて Cloudflare を経由します (§4)。異常な量のアクセスがあったときに、ロボットによるものでないかの確認画面を表示することがあります。Cloudflare が通信を処理する際に扱う情報は、[Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/) に従います
- アクセスログには、リクエストの ID・時刻・パス・結果を記録します。個人を特定できる情報は含めません。ログはサーバー上で自動的に上書きされ、長期に保存しません
- 予期しない不具合が起きた場合、例外の種類・メッセージ・発生箇所、アプリの版、処理の種類、個人を特定しない内部 ID を Sentry に送信します。原因調査のため、通信の一部を抽出し、画面の大まかな移動先、通信の種類・結果・所要時間を記録します
- ブラウザで不具合が起きた場合だけ、その直前の最大 60 秒間について、画面の構造と操作の流れを Sentry に送ることがあります。画面上のすべての文字と入力内容を伏せ、画像・SVG・動画は送信しません。通常の利用だけではこの記録を送信しません
- Sentry には Cookie、認証ヘッダー、IP アドレス、リクエスト・レスポンス本文、URL のクエリ文字列、利用者情報、SQL、console の内容、入力値、クリックした要素の文字列を送信しません

## 2. 画像の扱い

- スクリーンショットの現像はブラウザの中で行います。**スクリーンショットの原本はサーバーに送信されません**。現像の途中の内容と投稿前の画像は、利用者のブラウザの中 (IndexedDB) にだけ保存します
- 現像の「顔の認識」などは、ブラウザの中で行います。認識用のモデルは本サービスのサーバーから配り、**画像も認識の結果も外部に送信しません**
- 投稿したときにサーバーへ送るのは、現像した後の画像です。サーバーはそこから表示用・一覧用・共有プレビュー用の画像を作り、それだけを保存します。作った画像には撮影日時などのメタデータや、再編集のためにブラウザが画像に含めたデータを残しません。受け取った画像は、作り終えたら削除します
- 投稿の画像は、公開する前にサーバーの中で自動的に判定します (FINAL FANTASY XIV の画面らしさと、不適切な画像でないか)。**判定のために画像を外部に送ることはありません**
- 画像は Cloudflare R2 (オブジェクトストレージ) に保存し、Cloudflare を経由して配信します。非公開の投稿と、確認中・非表示の投稿の画像は、本人と運営にだけ本サービスのサーバーから返します
- **投稿画像および登録情報は、AI モデルの学習データとして利用しません**。第三者への提供も行いません

## 3. 情報の利用目的

- ログインと本人の識別
- 投稿の表示、検索、共有プレビュー (OGP) の生成
- 通報への対応、規約違反の防止、公開前の画像の確認
- 不正アクセスや過度な負荷の防止
- 本サービスの改善 (個人を特定しない集計に限ります)

## 4. 外部への送信

本サービスは次の外部サービスと通信します。Lumorphia アカウントへの送信を除き、**利用者の個人情報を送ることはありません**。

| 送信先                                        | 送る情報                                                                                                                                                                                                          | 目的                                                             |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Lumorphia アカウント (本サービスと同じ運営者) | ログインに必要な情報                                                                                                                                                                                              | ログイン、ログアウト                                             |
| XIVAPI                                        | なし (地名の一覧を週に 1 回取得するだけです)                                                                                                                                                                      | 撮影場所の候補の取得                                             |
| Cloudflare                                    | 本サービスへのすべての通信 (IP アドレス、閲覧したページ、ブラウザの種類など) と投稿画像 (作った画像)                                                                                                              | 通信の中継、過度なアクセスやロボットからの保護、画像の保存と配信 |
| Sentry                                        | 予期しないエラーの内容と発生箇所、アプリの版、処理の種類、個人を特定しない内部 ID、抽出した通信の種類・結果・所要時間。ブラウザのエラーのときは、文字・入力・画像を伏せた直前最大 60 秒間の画面の構造と操作の流れ | 不具合の検知と原因調査                                           |
| Discord                                       | 個人情報を含まない運用上の警告                                                                                                                                                                                    | 障害への対応                                                     |
| Google フォーム                               | お問い合わせフォームに入力した内容 (送信したときのみ)                                                                                                                                                             | 問い合わせの受け付け。内容は運営者だけが閲覧します               |

## 5. Cookie とブラウザの保存領域

本サービスは、ログイン状態を保つためのセッションの Cookie (ログインの途中で一時的に使うものを含みます) だけを使います。広告や行動追跡のための Cookie、第三者の解析ツールは使いません。

現像の途中の内容と投稿前の画像は、利用者のブラウザの保存領域 (IndexedDB) に置きます。本サービスのサーバーには送りません。

## 6. 保存期間と削除

| 情報                                                               | 期間                                                                                                        |
| ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| アカウントと投稿                                                   | 退会から 30 日後に、画像を含めて削除。30 日以内に復旧すれば元に戻ります                                     |
| 削除した投稿                                                       | 削除したときに直ちに削除 (画像も削除を始めます)                                                             |
| 通報                                                               | 通報した投稿か、通報した人のアカウントが削除されたときに削除                                                |
| Lumorphia アカウントからの退会・復旧・削除の知らせの受け取りの記録 | 知らせの ID、Lumorphia アカウントの ID、状態と時刻を、アカウントの削除まで保持 (古い知らせを当てないため)   |
| セッション (ログイン時の IP アドレスと User-Agent を含む)          | ログアウトまたは有効期限 (最長 30 日) で削除。退会したときは直ちに削除                                      |
| 運営の操作の記録 (確認、非表示、通報への対応など)                  | 1 年で削除。利用者は Lumorphia アカウントの ID か投稿の ID だけで記録し、名前やメールアドレスは記録しません |
| データベースのバックアップ                                         | 30 日で自動的に破棄                                                                                         |
| Sentry のエラー・trace・Replay 情報                                | 最長 30 日                                                                                                  |

**削除の方法**: Lumorphia アカウントの設定から、**本サービスだけ**または **Lumorphia アカウントごと**退会できます。個別の投稿は、投稿のページからいつでも削除できます。

## 7. 利用者の権利

利用者は、自分の投稿の確認・訂正・削除を本サービスで、ID・名前・アイコンを Lumorphia アカウントの設定で、自分で行えます。それで対応できない内容については、下記の問い合わせ先までご連絡ください。

## 8. 法令に基づく提供

法令に基づく開示請求や捜査機関からの正当な要請があった場合に限り、保有する情報を提供することがあります。

## 9. ポリシーの変更

このポリシーを変更する場合は、本ページに掲載します。取得する情報や送信先を増やす変更を行う場合は、ログイン後、投稿などの操作の前に改めて同意を求めます。

## 10. 問い合わせ先

このポリシーに関する問い合わせは、[お問い合わせ](/contact) からお願いします。
